# Nowhere Technical Guide

This website holds all public technical documents for the Office Nowhere Roblox game.

## Cookbook

The Cookbook goes over a real example of implementing a new feature, while utilizing packages used in Office Nowhere.

## Styling (Recommended)

Office Nowhere has a code style that derives from Roblox's official Luau style guide. The following guide will explain how to style and organize your code. Readable code is recomended, but isn't required as of now, but will be refactored in the future once Office Nowhere slowly leaves beta.
